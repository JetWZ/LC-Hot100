# Python ACM 模式入门

本目录配合 LeetCode Hot 100 教学，介绍 Python ACM 模式中的输入处理与常见数据结构构建。

## 学习内容

1. **读取数据**：`input()`、`sys.stdin`、二进制输入及 EOF。
2. **分割文本**：`split()`、`splitlines()` 与 `strip()`。
3. **类型转换**：`int()`、`float()`、`map()`、列表与解包。
4. **构建数据结构**：单向链表、完全二叉树、普通二叉树。
5. **存储图**：邻接矩阵与邻接表。

## 使用方式

- 打开 `ACM-mode.ipynb`，选择项目虚拟环境对应的 Python 内核。
- 按顺序运行单元格，先执行辅助函数定义。
- 输入实验通过 `use_input_file()` 从 UTF-8 TXT 文件读取数据。
- 相对路径以 Notebook 内核的当前工作目录为基准，可用 `Path.cwd()` 检查。
- 数据结构示例直接使用固定变量，重点展示构建与遍历过程。

## 示例约定

- 普通二叉树使用 `-1` 表示空节点，实际节点值不使用 `-1`。
- 图的节点编号从 1 开始，无向边需要双向存储。
- Notebook 辅助函数用于教学；提交判题系统时使用程序的标准输入。
